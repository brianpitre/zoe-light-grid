# Zoe Conference 2026 — Light Grid

Build reference for the Zoe 2026 "Light Grid": a canopy of 1,782
individually-hung LEDs (38 rows 16" apart × 52 positions @ 15" on center,
rows 27–38 curving in to 16 wide) on 10 named groups — every LED on hand
placed, nothing left over. Design locked 2026-09-21 (map digest `937cf403`).

**Live:** https://brianpitre.github.io/zoe-light-grid/

Sections: overhead map + animation modes · side section · rigging &
fishing-line cut list · cost · spec · row-by-row hang guide. No sliders — the
design is hard-coded and the page checks itself against the locked digest on load.

`index.html` is a self-contained copy of `light_grid_build.html` from the
working folder. To redeploy after edits, re-copy it over `index.html`, commit,
and push.
