01Overhead plan & mapping viewed from the floor

10 groups: 2 for JESUS · 3 star groups · 5 arcs. JESUS splits into two groups along an arc boundary — hide it by matching each half to its arc, reveal it by lighting both a shared color. This is the audience's view — looking up at the underside from the floor — so the word reads correctly here; the controller pixel-map (defined from above) is its left↔right mirror, applied when the map is cut. Row 1 is the upstage row (over the stage, drawn at the bottom); row 38 is downstage (over the crowd, at the top). Rows 27–38 round off in a curve so the grid holds exactly the LEDs on hand.

Reading the demo: waves roll upstage→downstage across the 5 arcs, the 3 star groups twinkle out of phase, then JESUS reveals — watch it lift out of the arcs and settle back in. Use JESUS hidden / shown to compare directly, and Group map to see which bin every light comes from (colored by group family: greens, whites, yellows, oranges, reds — the "1" of each color is the strong shade, the "2" is the pale one). The faint grey line behind each row is that row's installed wire rope.

Why these exact numbers: the ten group counts are the verified stock, so this design places every LED, with nothing left over. That drives everything: the grid holds exactly 1,782 positions (rows 1–26 full, rows 27–38 curving in to 16 wide); the five arcs are cut by rank from the wave center — 21 rows behind the upstage edge — so each arc is exactly its group's count (164 · 229 · 318 · 322 · 216, upstage to downstage); the stars are exactly 72 · 75 · 119; and the word is 267 cells — the full 8×14 letters with 29 corner cells removed, hand-picked so each letter reads cleanly (both S's chamfered at the top-right, the last S chamfered at the top-left so it can't read as a 5), which is what makes it equal Green 2 + White 1. The boundary between the two host arcs is placed inside the word so the upstage half is exactly Green 2's 155 lights; the same boundary splits the arc cells, so the camouflage is 100% — no JESUS light sits in an arc of another color. This design is hard-coded: no sliders anywhere. The page recomputes the map from the constants on load and checks it against the locked digest; if anyone edits a constant, the banner above turns red.

03Rigging & fishing-line cut list

One wire rope per row is already installed level across the width at the deck; each LED drops on its own fishing line. Rows 1–26 carry 52 LEDs; rows 27–38 carry 50 · 50 · 48 · 46 · 44 · 40 · 36 · 32 · 28 · 22 · 18 · 16.

Ordering allowance: add knot/tie-off to every drop (~10–15%). Row 1 = upstage (longest line, 19′ 0″); row 38 = downstage (shortest, 6′ 8″). Every row is exactly 4″ shorter than the one before — the same ladder as the original 40-row list; its 6′ 0″ and 6′ 4″ lengths are simply no longer used. Each length is used once per LED in that row — the LEDs column is the multiplier.

06Row-by-row hang guide volunteer build sequence · locked design

One strip per wire rope, Row 1 (upstage, over the stage) through Row 38 (downstage, over the crowd). Positions run 1–52 left to right, exactly as drawn in the overhead plan above; on rows 27–38 the outer positions are left empty (dashed) so the columns stay lined up with the rows above — the header of each strip says where its first light goes. Each square is one LED and its label is the group (bin) to pull from: G1/G2 = Green 1/2, W = White, Y = Yellow, O = Orange, R = Red. The line under each strip reads the same sequence as counts: 6×W2 means “six lights from White 2 in a row.” Line lengths match the cut list.

Group counts are exact: the legend reads placed / on hand for every bin and each one must match — when the last strip is hung, every bin is empty. Teal = matches, red = the page's map no longer matches the stock (a constant was edited).

Orientation check before hanging: this guide (like the overhead plan) is the audience’s view from the floor, looking up. If you lay wires out on the deck or work from above, left↔right is mirrored — agree on which physical end of each wire is position 1 before attaching the first light. Rows 27–38 are centered on their wires — measure from the wire's midpoint, not its end; each strip's header gives the distance from the wire end to its first light.
